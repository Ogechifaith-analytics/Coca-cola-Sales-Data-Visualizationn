# Coca-Cola Sales Performance Across Key US States - Data Visualization

## Overview

This data visualization provides an initial analysis of Coca-Cola sales performance across four key US states: California, Florida, New York, and Texas. The dashboard aims to highlight key trends in total sales, units sold, operating profit, operating margin, top-performing beverage brands, and major retailers in each state. This information can be valuable for understanding regional performance and identifying potential areas for strategic focus.

## Data Source

The data for this visualization originates from a single table containing sales information for the specified US states.

## Data Preparation Process

The following steps were involved in preparing the data for visualization:

1.  **Data Extraction:** Sales data for California, Florida, New York, and Texas were extracted from the primary sales table.
   
2.  **Field Identification:** Key fields relevant to the analysis were identified, including:
    * State
    * Total Sales
    * Unit Sold
    * Operating Profit
    * Operating Margin
    * Retailer
    * Beverage Brand
    
3.  **Data Type Verification:** The data types for each field were verified to ensure they were appropriate for analysis and visualization (e.g., ensuring sales and profit figures were numerical).
   
4.  **Data Structuring:** The data was structured to facilitate easy comparison and visualization across the different states and metrics. As the data was provided in a readily usable format for this summary, extensive restructuring was not required.

5.  **Data Cleaning:** Involve identifying and handling missing values, outliers, and inconsistencies.

## Key Visualizations and Insights

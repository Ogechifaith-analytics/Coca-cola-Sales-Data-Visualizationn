# Coca-Cola Sales Data Visualization Dashboard

## Overview

This dashboard provides a visual exploration of Coca-Cola sales data, offering insights into sales performance across different US states and beverage brands. It utilizes various visualizations to highlight key trends, identify top-performing brands, and understand the factors influencing operating profit.

## Data Source

The data for this visualization originates from a single table containing Coca-Cola sales information.

## Data Preparation Process

The following steps were undertaken to prepare the data for this dashboard:

1.  **Data Upload:** The Coca-Cola sales data table was uploaded to the powerBi.
2.  **Field Identification:** Key fields relevant to the analysis were identified, including:
    * State
    * Total Sales
    * Unit Sold
    * Operating Profit
    * Operating Margin
    * Retailer
    * Beverage Brand
      
3.  **Data Type Verification:** The data types for each field were verified to ensure they were appropriate for analysis and visualization (e.g., ensuring sales and profit figures were numerical, state names were categorical).
   
4.  **Data Cleaning:** standard data preparation such as:
    * Check for and handled missing values (e.g., identifying and potentially filtering out records with incomplete key information).
    * Ensure consistency in categorical data (e.g., standardizing state names and beverage brand names).
    * change to appropiate data type and use the accurate header.
      
5.  **Data Structuring for Visuals:** The data was structured in a way that allows for easy aggregation and filtering based on state and beverage brand, which is suitable for the chosen visualizations.

## Dashboard Visualizations and Insights

This dashboard utilizes the following visualizations to provide different perspectives on the Coca-Cola sales data:

* **Q&A AI Visual:** This allows users to ask natural language questions about the data and receive instant visual answers. It enables ad-hoc exploration and discovery of insights beyond the pre-defined visualizations.
* **Matrix to Summarize Beverage Brand Sales:** A matrix visual provides a tabular summary of sales performance metrics (e.g., Total Sales, Operating Profit) broken down by different beverage brands. This allows for easy comparison of brand performance.
* **Map for Sales Across States:** A geographical map visual displays sales performance (e.g., Total Sales, Operating Profit,Retailer) across different US states. This highlights regional variations and identifies top-performing geographical areas.
* **Key Influencer Analyzing Operating Profit by Beverage Brand:** This visual identifies the key factors (in this case, specific beverage brands) that most significantly influence the operating profit. It helps understand which brands are the strongest and weakest drivers of profitability.

## How to Use the Dashboard

* **Explore with Q&A:** Use the Q&A AI visual to ask specific questions about the data. For example, you could ask "What were the total sales in California?" or "Show me the operating profit for Dasani?".
* **Analyze Brand Performance:** Use the matrix visual to compare the sales and profitability of different Coca-Cola beverage brands. Identify top-selling and most profitable brands.
* **Understand Regional Sales:** Use the map visual to see how sales performance varies across different US states. Hover over states for detailed metrics. Identify key markets and potential areas for growth or concern.
* **Identify Profit Drivers:** Use the key influencer visual to understand which beverage brands have the most significant positive or negative impact on operating profit. This informs strategic decisions regarding product focus and marketing efforts.

## Important Considerations

* The accuracy and insights derived from this dashboard are dependent on the quality and completeness of the underlying data.
* The Q&A AI visual's effectiveness relies on the clarity and structure of the data and the user's phrasing of questions.
* The "Key Influencer" visual identifies correlations but does not necessarily imply causation. Other factors might also influence operating profit.
